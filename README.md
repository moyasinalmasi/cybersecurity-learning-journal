# Cybersecurity Learning Journal

This repository documents my structured learning journey in web application security, penetration testing, and bug bounty hunting.

My goal is to develop practical security testing skills through continuous study, hands-on labs, authorized bug bounty programs, and technical documentation.

## Current Focus

- Web application security
- Bug bounty methodology
- HTTP and web fundamentals
- Burp Suite
- JavaScript for security testing
- Reconnaissance and attack-surface mapping
- API security

## Vulnerability Topics

My current learning priorities include:

- Cross-Site Scripting (XSS)
- Broken Access Control and IDOR
- Authentication vulnerabilities
- Business logic vulnerabilities
- Cross-Origin Resource Sharing (CORS)
- Cross-Site Request Forgery (CSRF)
- SQL Injection
- Server-Side Request Forgery (SSRF)
- Template Injection
- Open Redirect
- API vulnerabilities

## Learning Process

For each security topic, I follow this workflow:

1. Study the underlying concepts and prerequisites.
2. Analyze real-world testing methodologies.
3. Practice in authorized labs and vulnerable environments.
4. Build a reusable testing checklist.
5. Apply the methodology to authorized bug bounty targets.
6. Document lessons, mistakes, and improvements.
7. Review previously studied topics regularly.

## Documentation Principles

- Sensitive information is never published.
- Real targets are anonymized unless public disclosure is explicitly authorized.
- Authentication tokens, cookies, private endpoints, and personal information are excluded.
- Lab solutions focus on methodology and lessons learned rather than copying payloads.
- All real-world security testing is performed only within authorized scope.

## Ethics

All activities documented in this repository are performed in legal training environments or explicitly authorized bug bounty programs. This repository is intended solely for education, ethical security research, and professional development.
