## Key Concepts

### IP Address

An IP address identifies a device on a network.

### Port

A port identifies a specific service or application running on a device.

### TCP

TCP is connection-oriented and focuses on reliable data delivery.

### UDP

UDP is connectionless and prioritizes speed over reliability.

### DNS

DNS translates domain names into IP addresses.

### NAT

NAT allows multiple devices on a private network to share a public IP address.
